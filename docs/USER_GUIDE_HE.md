# מדריך משתמש — Super Coder Cloud

## כניסה ראשונה
1. היכנסו לכתובת המערכת ולחצו **הרשמה**. מלאו שם מלא, אימייל וסיסמה (לפחות 10 תווים, אותיות ומספרים).
2. אשרו את המייל שנשלח אליכם.
3. במסך **בואו נקים את סביבת העבודה**: שם העסק, מזהה כתובת (באנגלית) ומטבע → **יצירת סביבת עבודה**.
4. רוצים לראות את המערכת בפעולה? בלוח הבקרה לחצו **טעינת נתוני דמו**. יופיע פס זהב "סביבת דמו" — הנתונים בדויים ולא יישלחו הודעות או תשלומים.

## אנשי קשר
- **איש קשר חדש** — שם פרטי חובה, ואימייל **או** טלפון חובה. טלפון אפשר להקליד בכל פורמט (`050-123-4567`, `+972 50…`).
- אי אפשר ליצור שני אנשי קשר עם אותו אימייל באותה סביבת עבודה.
- **חיפוש** — לפי שם, אימייל, חברה או ספרות מהטלפון. הלשוניות מסננות לפי סטטוס: ליד, מוסמך, לקוח, לא פעיל.
- בדף איש קשר: **עריכה**, **מחיקה**, **הוספת הערה** פנימית, והיסטוריית פעילות.
- **ייצוא CSV** — קובץ שנפתח נכון באקסל גם בעברית ובערבית (זמין למנהלים, שיווק ואנליסטים).
- סימון **הסכמה לקבלת דיוור שיווקי** נשמר עם תאריך ההסכמה.

## צוות והרשאות
- **הזמנת חבר צוות** — אימייל ותפקיד. יוצג קישור הזמנה **פעם אחת בלבד**; העבירו אותו למוזמן. הקישור תקף 7 ימים ורק לכתובת שהוזמנה.
- התפקידים: בעלים, מנהל מערכת, מנהל, שיווק, מכירות, תמיכה, אנליסט, לקוח, צפייה בלבד.
- אי אפשר להעניק תפקיד גבוה מהתפקיד שלכם, ואי אפשר להסיר את הבעלים האחרון.

## הגדרות
שם הארגון, אזור זמן, מטבע ושפת ברירת מחדל; השם והשפה שלכם; התראות; יומן ביקורת (למורשים).

## שפה ותצוגה
החלפת שפה (עברית / العربية / English) בתפריט המשתמש. מעבר בין מצב כהה לבהיר באייקון השמש/ירח.

## באייפון
המערכת עובדת ישירות בספארי. להתקנה כאפליקציה: כפתור **שיתוף** → **הוספה למסך הבית**.

## מודולים שמסומנים P2–P6
אלה מודולים מתוכננים שעדיין לא נבנו (אוטומציות, סוכני AI, קמפיינים ועוד). לחיצה עליהם מציגה את סטטוס הפיתוח — הם לא מציגים נתונים מדומים.
