# שדרוג Wave 26 — מה השתנה

## Shopify (חיבור חכם)
- זיהוי חכם של החנות: שם חנות ("My Store"), handle, דומיין אישי (www.mystore.co.il), כתובת Admin או קישור מלא — הכול הופך ל-`<handle>.myshopify.com` ונבדק מול Shopify **לפני** המעבר לאישור.
- בדיקה חיה תוך כדי הקלדה (✓ זוהתה: …), הצעות "להשתמש ב-…", הדבקת קישור מנוקה אוטומטית.
- אם ההמשך לא ניתן לאימות מראש (רשת) — לא חוסמים, Shopify מחליט.
- אחרי החיבור: ייבוא מיידי של ההזמנות האחרונות והעגלות הנטושות ל-CRM.
- כפתורים חדשים: "סנכרון עכשיו" ו"ניתוק החנות".
- אבטחה: חסימת כתובות פנימיות (SSRF), נתיב זיהוי רק למשתמש מחובר.

## קמפיינים
- פס מדדים (סה״כ, נשלחו, אחוז הצלחה, פעילים), סינון לפי סטטוס/ערוץ/חיפוש, פס התקדמות.
- דף קמפיין: אחוז הצלחה/כשל, פס שליחה חי, סינון נמענים לפי סטטוס עם ספירות.
- שכפול קמפיין בלחיצה (טיוטה חדשה).

## כניסה / הרשמה
- פס אמון מתחת לטפסים (אבטחה, התחלה בחינם, סוכני AI) בשלוש השפות.
