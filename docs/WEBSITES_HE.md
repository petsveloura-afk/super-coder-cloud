# אתרים מקצועיים, דומיינים ומסלולים (גל 13)

## מה מקבל כל לקוח
| | Free | Pro | Business |
|---|---|---|---|
| אתרים מפורסמים | 1 | 5 | 25 |
| תבניות עיצוב | 3 (קלאסי, מינימליסטי, רענן) | כל 10 | כל 10 |
| בנייה עם AI | דף נחיתה | אתר מלא + תמונה ב-AI | אתר מלא + תמונה ב-AI |
| עריכה עם הסוכן | – | ✓ | ✓ |
| דומיין משלך (חיבור או קנייה) | – | ✓ | ✓ |
| סימון "נבנה עם Super Coder" | מופיע | מופיע | בלי (White-label) |
| דפים משפטיים, תפריט נגישות, הודעת עוגיות | ✓ | ✓ | ✓ |
| יומן ביקורת | – | ✓ | ✓ |
| גישת API (מפתחות) | – | – | ✓ |

המגבלות נאכפות במסד הנתונים (`has_feature`, `plan_limit`). אתרים שכבר פורסמו נשארים פורסמים גם אם הלקוח יורד למסלול Free, אבל הוא לא יכול לפרסם אתרים נוספים מעבר למגבלה.

## בונה האתרים
- **אתרים ← אתר חדש**: מתארים את העסק, בוחרים תבנית או נותנים ל-AI לבחור, והאתר נבנה כטיוטה.
- **עורך האתר**, ארבע לשוניות:
  1. **תוכן ואזורים**: כותרת ראשית, יתרונות, אודות, גלריה, המלצות, מספרים, מחירון, איך זה עובד, צוות, לקוחות, וידאו, שאלות נפוצות, טופס, קביעת תור ויצירת קשר. אפשר להעלות תמונות לכל אזור.
  2. **עיצוב**: 10 תבניות, צבע ראשי ומשני, גופן, פינות, מצב בהיר או כהה ואנימציות.
  3. **פרטי עסק ודפים משפטיים**: שם רשמי, ח.פ., פרטי קשר, רשתות חברתיות, לוגו, כפתור וואטסאפ צף ושפת האתר. מדיניות פרטיות, תנאי שימוש, הצהרת נגישות ומדיניות עוגיות נוצרות אוטומטית מהפרטים, ואפשר לערוך אותן.
  4. **כתובת ודומיין**: הקישור הציבורי, ודומיין משלך.
- **עריכה עם הסוכן** (בראש העורך): כותבים מה לשנות ("תוסיף מחירון", "תעבור לעיצוב יוקרתי", "תתרגם לאנגלית"), והשינויים מופיעים בעורך לבדיקה. שום דבר לא מתפרסם לפני שמירה, ויש כפתור ביטול.
- **באתר המפורסם**: אנימציות כניסה, תפריט נגישות (הגדלת טקסט, ניגודיות, הדגשת קישורים, עצירת אנימציות), הודעת עוגיות, כפתור וואטסאפ ותחתית עם הדפים המשפטיים.

> הנוסחים המשפטיים הם תבנית כללית ואינם ייעוץ משפטי. כך גם כתוב לכל לקוח בעורך.

## דומיינים: הגדרה חד-פעמית (בעל המערכת)
המערכת קונה ומחברת דומיינים דרך חשבון ה-Vercel שלך. העלות נגבית מאמצעי התשלום שמוגדר ב-Vercel, והלקוח משלם לך עלות ועוד עמלה בכרטיס דרך PayPal.

1. **טוקן חדש ב-Vercel:**
   - נכנסים ל-Account Settings ← Tokens ← Create.
   - Scope: הצוות שבו נמצא הפרויקט.
   - **לא משתמשים בטוקן הישן שנחשף בצ'אט.**
2. **מזהה הפרויקט:** ב-Vercel ← הפרויקט super-coder-cloud ← Settings ← General ← Project ID.
3. **אם הפרויקט נמצא תחת צוות:** Team Settings ← General ← Team ID.
4. **ב-Vercel ← Environment Variables** (Production) מגדירים:
   - `VERCEL_API_TOKEN`, הטוקן החדש
   - `VERCEL_PROJECT_ID`
   - `VERCEL_TEAM_ID` (רק אם יש צוות)
   - לא חובה:
     - `DOMAIN_MARKUP_PERCENT`: אחוז העמלה, ברירת מחדל 30.
     - `DOMAIN_MIN_FEE_USD`: עמלה מינימלית, ברירת מחדל 5.
     - `DOMAIN_MAX_COST_USD`: המחיר המקסימלי שהמערכת תסכים לשלם, ברירת מחדל 60. כך דומיינים יקרים (פרימיום) לא נקנים אוטומטית.
5. **Redeploy.**
6. **בדיקה:** ב"ניהול הפלטפורמה" מופיע "רכישת דומיינים פעילה", עם טבלה של כל הדומיינים שנמכרו, העלות, המחיר והרווח.

**חשוב:**
- **PayPal:** חשבון ה-PayPal שלך צריך לקבל תשלומים בדולר (USD). זה בדרך כלל ברירת המחדל.
- **סדר הרכישה:** הדומיין נקנה רק אחרי שהתשלום של הלקוח נגבה ונבדק שהסכום נכון.
- **החזר אוטומטי:** אם הרישום נכשל, הכסף מוחזר ללקוח אוטומטית.
- **חידוש:** הדומיין נקנה לשנה, בלי חידוש אוטומטי. אפשר להפעיל חידוש אוטומטי עם `DOMAIN_AUTO_RENEW=true`, אבל אז החידוש נגבה ממך.
- **פרטי הלקוח:** פרטי בעל הדומיין נשמרים רק עד סיום הרישום, ואז נמחקים.

## איך הלקוח מחבר דומיין קיים
1. כתובת ודומיין ← "יש לי דומיין" ← מקלידים את הדומיין ← "חיבור".
2. אצל ספק הדומיין מוסיפים את הרשומות שמופיעות בטבלה:
   - `A @ 76.76.21.21`
   - `CNAME www cname.vercel-dns.com`
   - לפעמים גם `TXT` לאימות.
3. לוחצים "בדיקה עכשיו". כשהסטטוס "פעיל", האתר עולה על הדומיין עם SSL. שני הדפים המשפטיים נמצאים בכתובות `/privacy` ו-`/terms` של הדומיין.

## תת-דומיינים לכל האתרים (לא חובה)
אם יש לך דומיין, למשל `supercoder.agency`, אפשר לתת לכל אתר כתובת כמו `pet-line.sites.supercoder.agency`:
1. ב-Vercel מוסיפים לפרויקט את הדומיין `*.sites.supercoder.agency` (wildcard). זה דורש שהדומיין ינוהל ב-DNS של Vercel.
2. מגדירים `SITES_ROOT_DOMAIN=sites.supercoder.agency` ב-Vercel, ועושים Redeploy.

## תשלום מנוי: כרטיס וקריפטו בחלון אחד
בדף החיוב, הכפתור "כרטיס אשראי" פותח חלון אחד עם שתי לשוניות: כרטיס אשראי (בתוך האתר) ומטבעות דיגיטליים (NOWPayments). כפתור הקריפטו הנפרד נשאר כמו שהיה.
